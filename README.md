# Караоке «Эйфория» — демо-сайт

Статический одностраничный сайт: залы с переключателем, цены, акция, условия брони и калькулятор стоимости.

Открыть: `index.html` в браузере (папка `img/` рядом). Шрифт Montserrat подгружается с Google Fonts.

Форма брони ничего не отправляет. Данные и фото взяты со страницы заведения в Instagram (@euphoria_karaoke_kzl).
